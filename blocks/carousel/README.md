# carousel

Custom **carousel** block. Purpose: intro text beside a sliding set of image cards.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: optional leading rows without images = intro content (heading, text); then one row per slide with 4 cells: image, body (heading, text, CTA), card style, CTA style.

## Supported variations

No variations.
