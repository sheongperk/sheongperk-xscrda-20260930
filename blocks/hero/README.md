# hero

Custom **hero** block. Purpose: page-opening banner with heading, text and CTA.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: row 1 = image; row 2 = heading, text, CTA link. Optional config rows 3-6 (underline true/false, layout class, CTA style, background class) are read and hidden.

## Supported variations

| Variation | Option class |
| --- | --- |
| Image Left | `image-left` |
| Image Right | `image-right` |
| Image Top | `image-top` |
| Image Bottom | `image-bottom` |
| Image Background Text Left | `image-background-text-left` |
| Image Background Text Right | `image-background-text-right` |
| Theme Dark | `theme-dark` |
| Theme Light | `theme-light` |
| No Heading Underline | `removeunderline` |
