# carousel-gallery

Custom **carousel** block. Purpose: horizontally scrolling gallery of square social-post images, 3 per view on desktop, with prev/next arrows.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per gallery item: cell 1 = square image (optionally linked); optional cell 2 = caption paragraph (e.g. username). Always shows 3 square items per view (15px gap), full-bleed on mobile; caption renders as a white username overlay with an Instagram glyph; prev/next arrows appear from 900px (swipe on mobile).

No variations.
