# columns-benefits

Custom **columns** block. Purpose: full-bleed lifestyle banner with an overlapping white strip of 3 icon + label benefit links.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: row 1 (optional) = single cell with the banner image; row 2 = one cell per benefit, each an icon image + linked label (typically 3). A single-cell image-only first row is treated as the banner; without it the benefits render on their own.

## Supported variations

No variations.
