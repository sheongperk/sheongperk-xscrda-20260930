# carousel-featured

Custom **carousel** block. Purpose: one-at-a-time slider of featured hotels or restaurants: full-bleed image with an overlapping white panel (eyebrow, H3 name, description, CTA button / secondary link) and prev/next arrows.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per slide: cell 1 = image; cell 2 = eyebrow paragraph (location / hotel name), h3 name (optionally linked), optional detail paragraph (e.g. 'Cuisine: ...'), description paragraph, CTA link(s) (e.g. 'Discover Now', or 'VIEW RESTAURANT' + 'BOOK A TABLE').

## Supported variations

No variations.
