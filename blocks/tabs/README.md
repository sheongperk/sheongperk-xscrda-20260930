# tabs

Custom **tabs** block. Purpose: tabbed panels of related content.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: one row per tab: cell 1 = tab label; cell 2 = panel heading; cell 3 = heading level (h2-h6); cell 4 = image; cell 5 = panel body.
