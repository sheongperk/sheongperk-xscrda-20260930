# teaser

Custom **teaser** block. Purpose: promotional teaser with background image or video, swoosh overlay, title and button.

## Authoring (Document Authoring)

Model: `configuration`

Key/value rows (label in the first cell, value in the second): row 1 = title; row 2 = style (image or video); row 3 = video URL; row 4 = background image; row 5 = button text.

## Supported variations

No variations.
