# cards-offer

Custom **cards** block. Purpose: featured offer: full-bleed image with an overlapping white panel (eyebrow, title, BOOK NOW button); 2-up grid when more than one offer.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per offer: cell 1 = image; cell 2 = eyebrow paragraph, h3 (linked) title, CTA link.
