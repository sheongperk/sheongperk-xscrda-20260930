# columns

Custom **columns** block. Purpose: side-by-side content columns.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: each row has one cell per column; a cell holding only an image becomes an image column; a cell whose link points to a video (mp4/YouTube) renders a video.

## Supported variations

No variations.
