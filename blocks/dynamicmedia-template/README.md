# dynamicmedia-template

Custom **dynamicmedia-template** block. Purpose: renders a Dynamic Media (Scene7) template image with variable substitutions.

## Authoring (Document Authoring)

Model: `configuration`

Key/value rows (label in the first cell, value in the second): row 1 = source mode (inline); row 2 = Dynamic Media template URL; row 3 = comma-separated variable mapping (key=value).

## Supported variations

No variations.
