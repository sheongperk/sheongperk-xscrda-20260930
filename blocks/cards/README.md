# cards

Custom **cards** block. Purpose: grid of image + text cards.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: one row per card: cell 1 = image; cell 2 = body (heading, text, CTA link); optional cell 3 = card style class (default); optional cell 4 = CTA style class (default, cta-button, cta-button-secondary, cta-button-dark).

## Supported variations

| --- | --- |
| Gradient | `gradient` |
