# table

Custom **table** block. Purpose: tabular data.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: one row per table row, one cell per column; first row is the header unless no-header is set.

## Supported variations

| Variation | Option class |
| --- | --- |
| Striped | `striped` |
| Bordered | `bordered` |
| No Header | `no-header` |
